# folio — 個人資産ダッシュボード

ポートフォリオを端末内のSQLiteに保存するローカルWebアプリです。証券口座とは接続しません。

## 起動

Node.js 20以降を用意し、このフォルダで次を実行します。

```sh
npm install
npm run dev
```

ブラウザで http://127.0.0.1:5173 を開きます。初回は「設定」からAlpha VantageのAPIキーを登録してください。バックエンドは `127.0.0.1:4317` にだけ待ち受けます。データベースは `data/folio.sqlite` に作られます。

本番ビルドは `npm run build`、ビルド済み画面を含むローカルサーバーは `npm start` で起動します（http://127.0.0.1:4317）。

## 使い方

- 買付・売却の取引日、数量、約定価格、手数料、任意の目標価格を記録します。
- CSVの取引列は `symbol,name,market,currency,side,trade_date,quantity,price,fee,target_price,asset_type,entry_type` です。`asset_type` は `STOCK`、`FUND`、`CASH`、`entry_type` は通常取引の `TRADE` または基準日時点の残高 `OPENING` を使います。投資信託の口数は数量欄、価格は1万口あたりの基準価額として計算します。
- PDFのような保有残高一覧は、実際の売買履歴と区別するため、一覧の基準日を `trade_date` にし `entry_type=OPENING` で登録できます。現在価格を同じCSVから登録する場合は、追加列 `quote_price,quote_fetched_at,quote_source` を指定します。投資信託と現金は自動株価取得の対象外で、保有一覧の価格編集ボタンから手動更新できます。
- 日本株コードは `7203` または `7203.T` と入力できます。Alpha Vantage向けに `.TSE` 形式へ変換します。ティッカーが取得できない場合は、取引記録のティッカーを確認してください。
- 価格更新ボタンはAlpha Vantageの株価、主要地域ETFの参考価格、USD/JPYを取得します。銘柄ごとに4時間キャッシュし、APIの無料枠25リクエスト／日を超える呼び出しを止めます。無料枠・データ提供範囲は変更されることがあるため、Alpha Vantage側の条件に従ってください。
- 取引CSV、または設定画面から全取引・価格・記録済み評価額のJSONバックアップを出力・復元できます。バックアップにはAPIキーを含めません。
- 資産推移は価格更新時に保存された日次評価額です。USD資産の為替が未取得、または保有銘柄の価格が揃わない場合は、その日の評価額を記録しません。過去の価格を補完しません。

## 留意点

表示価格は取得できた最新値で、リアルタイムとは限りません。米国・欧州・日本の市場カードはSPY・VGK・EWJなどのETFを参考表示します。損益・目標価格との差は情報整理用であり、売買の推奨や投資助言ではありません。

株価APIへの接続には銘柄コードが送信されます。保有数量・約定価格・氏名はAPIに送信されません。Alpha VantageのAPIキーと取引情報はこのPC上のSQLiteデータベースに保存されます。ディスク暗号化やOSユーザー保護は別途有効にしてください。
